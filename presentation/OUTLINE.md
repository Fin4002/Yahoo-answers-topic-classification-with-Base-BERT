# Presentation Plan (8–12 min, single merged .mp4)

Spec §5.3 rules:

- Each member presents **2–3 minutes** and **introduces themselves by name**
- Screen-share the **notebook** (slides not necessary)
- Must cover: dataset & motivation, preprocessing decisions, model architectures, results, conclusions
- Camera may be off; merge all segments into one video; upload to Google Drive with view access

## Suggested segment plan (4 members)

| # | Member | Duration | Content |
|---|---|---|---|
| 1 | [Name] | ~3 min | Intro + motivation, dataset, EDA walkthrough (class distribution, length stats, word clouds) |
| 2 | [Name] | ~2.5 min | Preprocessing decisions + representation comparison (TF-IDF vs Word2Vec vs GloVe) |
| 3 | [Name] | ~3 min | Model architectures: classic ML, RNN family, BERT; hyperparameter tuning tables |
| 4 | [Name] | ~3 min | Results: comparison table + confusion matrices, best/worst models, conclusions + limitations |

## Recording tips

- Record at 1080p, ~24–30 fps; keep notebook outputs visible (zoom into figures/tables)
- Script each segment to hit the time budget; rehearse once before recording
- Merge with any editor (DaVinci Resolve, CapCut, `ffmpeg`); name: `GroupNo_ID1_ID2_ID3_ID4.mp4`

## Viva prep (spec §6)

Everyone must be able to explain **any** part: the preprocessing choices, why each representation/model won/lost, what each hyperparameter does, and where AI tools assisted. Run a mock viva: each member explains a section they didn't own.
